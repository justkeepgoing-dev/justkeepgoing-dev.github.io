Codex cloud · Hermes Studio

개인 작업을 위한 운영 도구

Google 계정 연결과 데이터 사용 안내

서비스 소개

Codex cloud (Hermes Studio)는 운영자의 개인 작업을 위한 비공개 운영 도구입니다. Google 계정 연결을 통해 YouTube 현황을 확인하며, 실제 도구에는 Tailscale을 통한 사설 접근을 사용합니다. 이 페이지는 서비스와 권한을 설명하는 공개 안내 페이지입니다.

Google 계정 접근 권한

YouTube 및 YouTube Analytics

https://www.googleapis.com/auth/youtube.readonly와 https://www.googleapis.com/auth/yt-analytics.readonly를 사용하여 채널 및 분석 데이터를 읽고, 일별 조회수와 좋아요를 확인합니다. 기본 조회 범위는 최근 90일이며 운영자의 미니 PC에 캐시하고 6시간마다 갱신합니다.

Google Drive

동일한 Google OAuth 앱은 별도의 개인 작업 도구에서도 https://www.googleapis.com/auth/drive 권한을 사용합니다. 이 권한은 읽기 전용이 아닌 읽기·쓰기 권한입니다. 해당 도구는 파일 검색·읽기, 업로드·다운로드, 생성·공유·삭제를 지원하며 작업에는 별도의 사용자 승인이 필요합니다. Drive 작업은 반드시 Hermes Studio 백엔드에서 수행되는 것은 아닙니다.

데이터와 선택권

Google API를 호출할 때 해당 요청과 데이터가 Google로 전송됩니다. YouTube와 Drive의 인증 토큰은 별도 파일로 저장됩니다. 데이터 처리와 연결 해제 방법은 개인정보 처리방침을 확인하세요.
