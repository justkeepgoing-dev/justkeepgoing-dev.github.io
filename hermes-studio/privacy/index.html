개인정보 처리방침

최종 업데이트: 2026년 11월 19일

1. 적용 범위와 목적

이 방침은 개인 운영 도구 Codex cloud (Hermes Studio)와 동일 Google OAuth 앱을 사용하는 별도 개인 작업 도구의 Google 계정 데이터 처리에 대해 설명합니다. YouTube 데이터는 채널 현황과 일별 분석 지표 확인에 사용하고, Drive 데이터는 승인된 파일 작업을 수행하는 데 사용합니다.

2. 접근하는 데이터와 권한

  • https://www.googleapis.com/auth/youtube.readonly: YouTube 채널 데이터를 읽습니다.
  • https://www.googleapis.com/auth/yt-analytics.readonly: YouTube Analytics의 일별 조회수와 좋아요를 읽습니다.
  • https://www.googleapis.com/auth/drive: Google Drive 파일에 대한 폭넓은 읽기·쓰기 권한입니다. 별도 도구에서 검색·읽기, 업로드·다운로드, 생성·공유·삭제를 지원하며 작업에는 별도의 사용자 승인이 필요합니다. 이 작업이 반드시 Studio 백엔드에서 이뤄지는 것은 아닙니다.

YouTube 권한과 달리 Drive 권한은 읽기 전용이 아닙니다.

3. 저장 및 전송

YouTube 분석은 기본적으로 최근 90일을 조회하며, 결과는 운영자의 미니 PC에 캐시되고 6시간마다 갱신됩니다. 90일은 기본 조회 범위이며 데이터 보관 또는 삭제 기한을 뜻하지 않습니다. YouTube와 Drive 인증 토큰은 별도 파일로 저장됩니다.

실제 도구는 Tailscale을 통해 사설 접근하며, Google API 호출 시 요청과 관련 데이터가 Google로 전송됩니다.

4. 연결 해제 및 삭제 요청

Google 계정의 연결된 앱 설정에서 접근 권한을 철회할 수 있습니다. 같은 OAuth 클라이언트를 사용하는 다른 기능에도 영향이 있을 수 있습니다. 철회와 별개로 로컬에 저장된 토큰과 캐시 삭제를 요청할 수 있으며, 삭제는 운영자가 별도로 수행해야 합니다.
